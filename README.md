# RecallDeck

A lightweight spaced-repetition flashcard app for students. Create question/answer cards, review what is due, rate recall, and build a daily streak. Your deck is stored locally in your browser; no account or server required.

## Features
- Due-card review with Again, Hard, and Got it scheduling
- Growing review intervals saved per card
- Daily study streak tracking
- Add and delete cards, due count and deck overview
- Responsive interface and escaped user content
- Vanilla HTML, CSS, JavaScript. No API keys or backend.

## Run
Open `index.html` in a browser, or host the files as a static website. Data stays in that browser's local storage.

## Theme
A distinct lilac-and-violet study studio: Plus Jakarta Sans, DM Mono, soft lavender canvas, rounded white cards, and a violet gradient accent. This avoids the previous dark developer-dashboard palette and the warm paper/forest ClassCue look.
